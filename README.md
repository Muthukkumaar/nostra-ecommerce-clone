# Nostra — Responsive E-Commerce Website

A modern, responsive multi-page fashion e-commerce web application featuring dynamic product search, multi-category filtering, and mobile-first navigation.

---

## ✨ Features

- **Responsive Multi-Page Layout:** Seamless navigation across **Home**, **Collections**, and **Contact Us** pages, adapting cleanly across desktop, tablet, and mobile viewports.
- **Interactive Navigation:** Includes a dismissible top promotional banner and a slide-out mobile drawer menu.
- **Real-Time Product Search:** Instantly filters products by name as the user types on the Collections page.
- **Multi-Category Filtering:** Filter items simultaneously by **Occasion** (Summer, Party, Beach), **Color** (Red, Blue, White, Green), and **Arrival** (New, Old) with a one-click reset option.
- **Interactive UI Elements:** Includes wishlist heart toggles on featured products and client-side contact form submission feedback.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure across all pages
- **CSS3:** Custom properties, Flexbox, CSS Grid, and responsive media queries
- **JavaScript (ES6+):** DOM manipulation, live search filtering, multi-checkbox state handling, and interactive UI toggles
- **Font Awesome:** Scalable vector icons
